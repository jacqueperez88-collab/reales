# 🔢 Números Reales - Matemática General (UNComa)

Bienvenido al repositorio del material educativo interactivo sobre **Números Reales**, diseñado especialmente para estudiantes de la Facultad de Informática / FaEA de la Universidad Nacional del Comahue (UNComa).

🔗 **Ver la página en vivo:** [https://jacqueperez88-collab.github.io/reales/](https://jacqueperez88-collab.github.io/reales/)

---

## 📚 Descripción
Este proyecto es una página web didáctica, visual e interactiva que resume la teoría y ofrece ejercicios prácticos resueltos paso a paso sobre los fundamentos de los números reales. El contenido está basado en los apuntes oficiales de la cátedra de Matemática General e Introducción a la Matemática, adaptado a un formato digital moderno para facilitar el estudio, la práctica y la autoevaluación.

## ✨ Características Principales
- 🎨 **Diseño Visual Atractivo**: Paleta de colores pasteles cuidadosamente elegida para reducir la fatiga visual y crear una experiencia de aprendizaje agradable.
- 🧮 **Renderizado LaTeX Profesional**: Todas las fórmulas matemáticas, intervalos, valor absoluto y fracciones están escritas en LaTeX y renderizadas en tiempo real usando **MathJax**, garantizando una tipografía académica impecable.
- 🔄 **Interactividad**: Botones para mostrar/ocultar las resoluciones, permitiendo a los estudiantes intentar los ejercicios por su cuenta antes de corroborar sus resultados.
- 📱 **Diseño Responsive**: Se adapta perfectamente a computadoras de escritorio, tablets y teléfonos móviles.

## 📂 Temas Cubiertos
La página está organizada en secciones de navegación intuitiva que abarcan:
1. **Conjuntos Numéricos**: Números Naturales (ℕ), Enteros (ℤ), Racionales (ℚ), Irracionales (𝕀) y Reales (ℝ). Propiedades y operatoria básica.
2. **Ecuaciones**: Resolución de ecuaciones de primer y segundo grado, y planteo de modelos matemáticos.
3. **Inecuaciones**: Conceptos básicos, intervalos, inecuaciones lineales, cuadráticas y racionales.
4. **Valor Absoluto**: Definición geométrica, propiedades, ecuaciones e inecuaciones con valor absoluto.
5. **Ecuaciones Racionales (Fraccionarias)**: Resolución y condiciones de existencia (descarte de valores que anulan el denominador).

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica y accesible del contenido.
- **CSS3**: Estilos personalizados, gradientes, animaciones suaves y diseño *mobile-first*.
- **JavaScript (Vanilla)**: Lógica ligera para la navegación entre pestañas y el toggle (mostrar/ocultar) de las soluciones.
- **MathJax**: Librería JavaScript para el renderizado de fórmulas matemáticas en LaTeX (`$ ... $` y `$$ ... $$`).

## 🚀 Cómo usar este recurso
1. Accede directamente a la página publicada a través del enlace de [GitHub Pages](https://jacqueperez88-collab.github.io/reales/).
2. Utiliza el menú de navegación superior para saltar entre los diferentes temas.
3. Lee la teoría resumida en las cajas de color y revisa las propiedades clave.
4. Intenta resolver los ejercicios propuestos en tu cuaderno.
5. Haz clic en el botón **"Ver Solución"** para desplegar el desarrollo paso a paso y verificar tu resultado.
