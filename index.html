Inecuaciones

Conceptos Básicos e Intervalos

Definición: Las inecuaciones son expresiones matemáticas que establecen relaciones de desigualdad entre dos cantidades o expresiones algebraicas.

Monotonía del Producto:

• Si multiplicamos por un número positivo, la desigualdad mantiene el sentido.

• Si multiplicamos por un número negativo, la desigualdad cambia su sentido.

Intervalos:

• Abierto: (a, b) = {x ∈ ℝ : a < x < b}

• Cerrado: [a, b] = {x ∈ ℝ : a ≤ x ≤ b}

• Infinitos: (a, +∞), (-∞, a], etc.

Inecuaciones Cuadráticas

Propiedad del Producto (Clave para resolver):

• a · b > 0 ⟺ (a > 0 y b > 0) ó (a < 0 y b < 0)

• a · b < 0 (a > 0 y b < 0) ó (a < 0 y b > 0)

• a · b ≥ 0 ⟺ (a ≥ 0 y b ≥ 0) ó (a ≤ 0 y b ≤ 0)

Para que un producto sea positivo, los factores deben tener el mismo signo. Para que sea negativo, deben tener signos opuestos.

Ejercicios - Inecuaciones Cuadráticas

Ejercicio Cuadrático 1:
(x - 4)(x + 3) > 0

Resolución: Aplicamos la propiedad a · b > 0

Caso 1: (x - 4 > 0 y x + 3 > 0) ⟹ (x > 4 y x > -3) ⟹ Intersección: (4, +∞)

Caso 2: (x - 4 < 0 y x + 3 < 0) ⟹ (x < 4 y x < -3) ⟹ Intersección: (-∞, -3)

Unimos ambos casos:

Solución: (-∞, -3) ∪ (4, +∞)

Ejercicio Cuadrático 2:
x² - 5x + 6 ≥ 0

Resolución: Primero factorizamos la ecuación cuadrática:

x² - 5x + 6 = (x - 2)(x - 3)

La inecuación queda: (x - 2)(x - 3) ≥ 0. Aplicamos la propiedad a · b ≥ 0

Caso 1: (x - 2 ≥ 0 y x - 3 ≥ 0) ⟹ (x ≥ 2 y x ≥ 3) ⟹ Intersección: [3, +∞)

Caso 2: (x - 2 ≤ 0 y x - 3 ≤ 0) ⟹ (x ≤ 2 y x ≤ 3) ⟹ Intersección: (-∞, 2]

Unimos ambos casos:

Solución: (-∞, 2] ∪ [3, +∞)

Inecuaciones Racionales

Propiedad del Cociente:

• a/b > 0 ⟺ (a > 0 y b > 0) ó (a < 0 y b < 0)

• a/b < 0 ⟺ (a > 0 y b < 0) ó (a < 0 y b > 0)

• a/b ≥ 0 ⟺ (a ≥ 0 y b > 0) ó (a ≤ 0 y b < 0)

⚠️ Importante: Si la inecuación no tiene 0 en el lado derecho (ej: > 1), debemos restar ese número para obtener 0 antes de aplicar la propiedad. Además, el denominador nunca puede ser cero.

📝 Ejercicios - Inecuaciones Racionales

Ejercicio Racional 1:
(x - 3) / (4 - x) > 0

Resolución: Aplicamos la propiedad a/b > 0

Caso 1: (x - 3 > 0 y 4 - x > 0) ⟹ (x > 3 y x < 4) ⟹ Intersección: (3, 4)

Caso 2: (x - 3 < 0 y 4 - x < 0) ⟹ (x < 3 y x > 4) ⟹ No existe x que cumpla ambas (∅)

Unimos ambos casos:

Solución: (3, 4)

Ejercicio Racional 2:
(x - 3) / (4 - x) > 1

Resolución: ¡Ojo! No podemos aplicar la propiedad directa porque hay un 1 a la derecha. Restamos 1 en ambos miembros:

(x - 3)/(4 - x) - 1 > 0

Común denominador: [(x - 3) - (4 - x)] / (4 - x) > 0

(x - 3 - 4 + x) / (4 - x) > 0

(2x - 7) / (4 - x) > 0

Ahora sí aplicamos la propiedad a/b > 0:

Caso 1: (2x - 7 > 0 y 4 - x > 0) ⟹ (x > 7/2 y x < 4) ⟹ Intersección: (7/2, 4)

Caso 2: (2x - 7 < 0 y 4 - x < 0) ⟹ (x < 7/2 y x > 4) ⟹ No existe (∅)

Solución: (7/2, 4)

Ejercicios Prácticos - Inecuaciones Lineales

Ejercicio 1a:
x - 23 ≤ 0

Resolución: x ≤ 23

Solución: (-∞, 23]

Ejercicio 1b:
2x - 1 > x + 2

Resolución: 2x - x > 2 + 1 ⟹ x > 3

Solución: (3, +∞)

Ejercicio 1c:
3 ≤ 2x + 1 ≤ 10

Resolución: 2 ≤ 2x ≤ 9 1 ≤ x ≤ 4.5

Solución: [1, 4.5]

Ejercicio 1d:
(x + 5)(x - 7) ≥ 0 y x ≥ 0

Resolución: (x+5)(x-7)≥0 ⟹ x≥7 ó x≤-5. Intersectando con x≥0:

Solución: [7, +∞)

Ejercicio 1e:
(x - 6)/(x + 2) < 1

Resolución: (x - 6)/(x + 2) - 1 < 0 ⟹ -8/(x + 2) < 0. Como -8 es negativo, necesitamos x + 2 > 0 ⟹ x > -2

Solución: (-2, +∞)

Ejercicio 1f:
x³ - x² ≥ 0

Resolución: x²(x - 1) ≥ 0. Como x² ≥ 0 siempre, necesitamos x - 1 ≥ 0 ⟹ x ≥ 1. O x = 0.

Solución: {0} ∪ [1, +)

Ejercicio 1g:
3x - 5 ≠ 0

Resolución: x ≠ 5/3

Solución: (-∞, 5/3) ∪ (5/3, +∞)

Ejercicio 1h:
(x - 2)(x - 4) ≠ 0

Resolución: x ≠ 2 y x ≠ 4

Solución: (-∞, 2) ∪ (2, 4) ∪ (4, +∞)

Ejercicio 1i:
(x + 4)/(x - 3) ≠ 0

Resolución: Numerador ≠ 0: x ≠ -4. Denominador ≠ 0: x ≠ 3

Solución: (-∞, -4) ∪ (-4, 3) ∪ (3, +∞)

Ejercicio 1j:
x³ < 4

Resolución: x < ∛4

Solución: (-, ∛4)

Ejercicio 1k:
(x - 3)² > 5

Resolución: |x - 3| > √5 ⟹ x - 3 > √5 ó x - 3 < -√5

Solución: (-, 3-√5) ∪ (3+√5, +∞)

Ejercicio 1l:
√(x - 1) ≤ 12

Resolución: Condición: x - 1 ≥ 0 ⟹ x ≥ 1. Luego x - 1 ≤ 144 ⟹ x ≤ 145

Solución: [1, 145]

Valor Absoluto

Definición y Propiedades

Definición: |x| = { x si x ≥ 0; -x si x < 0 }. Representa la distancia de un número al cero.

Propiedades:

1. |x| ≥ 0 | 2. |x| = 0 ⟺ x = 0 | 3. |x| = d (d > 0) ⟺ x = d ó x = -d

4. |xy| = |x||y| | 5. |x| ≤ d ⟺ -d ≤ x ≤ d | 6. |x| ≥ d ⟺ x ≤ -d ó x ≥ d

Ejercicios Prácticos - Valor Absoluto

Ejercicio 2a:
|x - 2| = 3

Resolución: x - 2 = 3 ó x - 2 = -3 x = 5 ó x = -1

Solución: S = {-1, 5}

Ejercicio 2b:
|2x + 4| ≤ 0

Resolución: El valor absoluto siempre es ≥ 0. La única posibilidad es |2x + 4| = 0 ⟹ x = -2

Solución: S = {-2}

Ejercicio 2c:
(x + 4)² - 3 = 0

Resolución: (x + 4)² = 3 ⟹ x + 4 = ±√3 ⟹ x = -4 ± 3

Solución: S = {-4-√3, -4+√3}

Ejercicio 2d:
|3x - 1| > 9

Resolución: 3x - 1 > 9 ó 3x - 1 < -9 3x > 10 ó 3x < -8 ⟹ x > 10/3 ó x < -8/3

Solución: (-∞, -8/3) ∪ (10/3, +∞)

Ejercicio 2e:
-2|x + 3/5| ≥ -12

Resolución: |x + 3/5| ≤ 6 (cambia el sentido al dividir por -2) ⟹ -6 ≤ x + 3/5 ≤ 6 ⟹ -33/5 ≤ x ≤ 27/5

Solución: [-33/5, 27/5]

Ejercicio 2f:
|x + 3| - 4 = (1/2)x - 1

Resolución:

Caso 1: x + 3 ≥ 0 → x ≥ -3. x + 3 - 4 = (1/2)x - 1 ⟹ x = 0 (cumple) ✓

Caso 2: x + 3 < 0 → x < -3. -(x + 3) - 4 = (1/2)x - 1 ⟹ x = -4 (cumple) ✓

Solución: S = {-4, 0}

Ejercicio 2g:
|x - 4| ≥ -2

Resolución: El valor absoluto siempre es ≥ 0, y 0 ≥ -2. Siempre es verdadera.

Solución: S = ℝ = (-∞, +)

Ejercicio 2h:
2 < |x - 1| ≤ 5

Resolución: |x - 1| > 2 ⟹ x > 3 ó x < -1. Y |x - 1| ≤ 5 ⟹ -4 ≤ x ≤ 6. Intersectando:

Solución: [-4, -1) ∪ (3, 6]

Ejercicio 2i:
2|x + 3| - 8 > x - 2

Resolución:

Caso 1: x ≥ -3. 2(x + 3) - 8 > x - 2 ⟹ x > 0. Intersección: x > 0

Caso 2: x < -3. -2(x + 3) - 8 > x - 2 ⟹ x < -4. Intersección: x < -4

Solución: (-, -4) ∪ (0, +)

Ecuaciones Racionales

Conceptos Básicos

Definición: Ecuación fraccionaria: P(x)/Q(x) = 0. Es suficiente que el numerador sea 0, descartando los valores que anulan el denominador (división por cero no está definida).

📝 Ejercicios Prácticos - Ecuaciones Racionales

Ejercicio 1:
(x - 4)/x = 3

Resolución: Condición: x ≠ 0. x - 4 = 3x ⟹ -4 = 2x ⟹ x = -2. Verificamos: -2 ≠ 0 ✓

Solución: S = {-2}

Ejercicio 2:
2(1 - x)/x = (x - 6)/4

Resolución: Condición: x ≠ 0. 8(1 - x) = x(x - 6) 8 - 8x = x² - 6x ⟹ x² + 2x - 8 = 0 ⟹ x₁ = 2, x₂ = -4

Solución: S = {-4, 2}

Ejercicio 3:
1/(2x) + 1/4 - 1/(10x) = 1/5

Resolución: Condición: x ≠ 0. mcm = 20x. [10 + 5x - 2]/(20x) = 1/5 ⟹ 5(5x + 8) = 20x ⟹ 25x + 40 = 20x x = -8

Solución: S = {-8}

Ejercicio 4:
(x - 8)/(x - 1) = (2x - 4)/(x + 2)

Resolución: Condiciones: x ≠ 1, x ≠ -2. (x - 8)(x + 2) = (2x - 4)(x - 1) x² - 6x - 16 = 2x² - 6x + 4 x² = -20. No tiene solución en ℝ.

Solución: S = ∅

Conjuntos Numéricos

Resumen de Conjuntos

Naturales (ℕ): {1, 2, 3...} | Enteros (ℤ): {...-2, -1, 0, 1, 2...} | Racionales (ℚ): {m/n : m,n ∈ ℤ, n≠0} | Reales (ℝ): ℚ ∪ Irracionales

Ejercicios Prácticos - Conjuntos Numéricos

Ejercicio 1:
¿Es posible encontrar un número natural que restado a 32 dé 38?

Resolución: 32 - x = 38 ⟹ x = -6. Como -6 ∉ ℕ, no existe.

Solución: S = ∅

Ejercicio 2:
Completar: |-105| ... |64|

Resolución: |-105| = 105 y |64| = 64. Como 105 > 64

Solución: |-105| > |64|

Ejercicio 3:
Si a es positivo, entonces |a| ... a

Resolución: Si a > 0, por definición |a| = a.

Solución: |a| = a

Ejercicio 4:
¿196 y 245 son múltiplos de 7?

Resolución: 196 = 7 × 28 y 245 = 7 × 35. Sí, ambos son múltiplos. Su suma (441 = 7 × 63) también lo es.

Solución: Sí, ambos son múltiplos de 7

Ecuaciones de Primer y Segundo Grado

Teoría

1er Grado: ax + b = 0 ⟹ x = -b/a

2do Grado: ax² + bx + c = 0 ⟹ x = (-b ± √(b² - 4ac))/(2a)

Discriminante (Δ): Si Δ > 0 (2 soluciones), Δ = 0 (1 solución doble), Δ < 0 (Sin solución real).

📝 Ejercicios Prácticos - Ecuaciones

Ejercicio 1:
3(x - 2) + 1 = 2x

Resolución: 3x - 6 + 1 = 2x ⟹ 3x - 5 = 2x ⟹ x = 5

Solución: S = {5}

Ejercicio 2:
x² - 5x + 6 = 0

Resolución: Δ = 25 - 24 = 1. x = (5 ± 1)/2 ⟹ x₁ = 3, x₂ = 2

Solución: S = {2, 3}

Ejercicio 3:
x² + x + 1 = 0

Resolución: Δ = 1 - 4 = -3 < 0. No tiene raíces reales.

Solución: S = ∅
